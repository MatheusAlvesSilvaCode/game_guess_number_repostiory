# Number Guessing Game

A command-line interface (CLI) application built in Java where players attempt to guess a secret number randomly generated by the computer within a limited number of attempts.

This project is a solution to the [**Number Guessing Game**](https://roadmap.sh/projects/number-guessing-game?utm_source=gemini) project from [roadmap.sh](https://roadmap.sh?utm_source=gemini).

## Features

* **3 Difficulty Levels**:
  * **Easy**: 10 attempts
  * **Medium**: 5 attempts
  * **Hard**: 3 attempts
* **Real-time Feedback**: Get hints after every guess indicating whether the secret number is **GREATER** or **SMALLER**.
* **Input Validation**: Ensures valid integer inputs when selecting options.
* **Play Again Option**: Allows players to restart a new round immediately upon winning or losing without restarting the application.

## Built With

* **Language**: Java (JDK 8 or higher)
* **API**: `java.util.Scanner`, `java.util.Random`

## Project Structure

## Getting Started

### Prerequisites

* [Java Development Kit (JDK)](https://www.oracle.com/java/technologies/downloads/?utm_source=gemini) version 8 or higher installed.
* `javac` and `java` available in your system's PATH.

### Installation & Execution

1. **Clone the repository**:

   ```bash
   git clone https://github.com/<your-username>/<your-repo-name>.git
   cd <your-repo-name>
   ```

2. **Compile the Java source files**:

   ```bash
   javac MainGame.java GameGuess.java
   ```

3. **Run the game**:

   ```bash
   java MainGame
   ```

## How to Play

1. Run the application.
2. Select your desired difficulty level (`1` for Easy, `2` for Medium, `3` for Hard).
3. Type a number between **1** and **100** and press `Enter`.
4. Read the feedback provided by the game:
   * **`GREATER`**: The target number is higher than your guess.
   * **`SMALLER`**: The target number is lower than your guess.
5. Guess the correct number before you run out of attempts!
